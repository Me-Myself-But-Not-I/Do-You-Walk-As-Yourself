# Do-You-Walk-As-Yourself

"Do you walk as Yourself?" is an entry for the Brackey's Game Jam 2026.
It is a 2D game, with influence taken from the popular Turing game "Human or Not?"

It was developed by Samuel Dingle and Samuel Jordan.

## Tools used:
- Ableton Live 12 Suite
- Aseprite
- IntelliJ Idea Ultimate
- Jetbrains Rider
- Unity Engine
